Formato del sprite sheet:

Una imagen PNG donde cada fila es una animación y cada columna es un frame. Todos los frames deben ser de 32×32 px.

  • Ancho y alto múltiplos de 32
  • Mínimo 128×160 px (4 columnas × 5 filas)

Filas obligatorias:

  • Fila 0 — idle: animación de reposo (loop)
  • Fila 1 — blink: parpadeo (se reproduce una vez)
  • Fila 2 — look_left: mirar a la izquierda
  • Fila 3 — look_right: mirar a la derecha
  • Fila 4 — drag: siendo arrastrado / cayendo

Filas opcionales (para emociones):

  • Fila 5 — sleep: dormido (idle prolongado)
  • Fila 6 — wave: saludar (al conectar)
  • Fila 7 — celebrate: celebrar (respuesta recibida)
  • Fila 8 — think: pensando (esperando respuesta)
  • Fila 9 — sad: triste (desconectado)

Si una fila opcional no existe, se usa un fallback automático (think→blink, celebrate→idle rápido, etc).

API HTTP local
Permite que otros programas de tu PC se comuniquen con el critter mediante peticiones HTTP. Por ejemplo, un script puede enviar un mensaje al critter o consultar su estado.
Habilitar API local
Requiere reiniciar la app para aplicar cambios
Endpoints disponibles
  • POST /message — envía texto al critter: { "text": "hola" }
  • GET /status — estado de conexión, versión
  • POST /action — ejecuta una acción: { "action": "wave" }
  • POST /webhook — trigger externo: { "event": "notify", "data": {"text": "..."} }

Plugins
Los plugins agregan comportamientos, animaciones y herramientas al critter sin modificar el código principal. Se cargan automáticamente desde la carpeta de plugins al iniciar.
Habilitar sistema de plugins
Plugins instalados
  • Sin plugins instalados

Crear un plugin:

  • Crear una carpeta dentro de plugins/
  • Agregar plugin.json con name, version, description
  • Opcional: animations (sprite rows), states (FSM), init (script JS)
  • El plugin recibe acceso limitado al eventBus (emit/on) y config (get)
